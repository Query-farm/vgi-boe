# Official Bank Rate XML recordings

These four files are unchanged public responses for IUDBEDR from the Bank of
England Interactive Database, retrieved on 14 November 2026 UTC. They cover
December anchors and calendar years 2023/2024. `manifest.json` records each exact
URL, request parameters, retrieval timestamp, content type, size and SHA-256.
The replay server rejects different queries and verifies the files before use.

Source: Bank of England. Copyright the Governor and Company of the Bank of
England. Reused under the [Open Government Licence v3.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/).
See [database terms](https://www.bankofengland.co.uk/legal#bank-of-england-database)
and [download documentation](https://www.bankofengland.co.uk/boeapps/database/help.asp).
These current-source historical observations are not an as-of vintage archive.

The local `.gitattributes` preserves original XML bytes and line endings across
Git checkouts. Upstream whitespace is retained intentionally for checksum fidelity.
